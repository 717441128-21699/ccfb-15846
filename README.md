# 弓道 · 弹性箭杆射箭模拟

传统弓 / 反曲弓射箭游戏的物理核心与 WebGL2 演示。箭不再是刚性直棍，而是按
**欧拉-伯努利自由梁一阶弯曲模态**建模的弹性杆：撒放时弓弦推力激发弯曲振动，
箭身绕过弓把（弓箭手悖论），飞行中靠羽毛风标效应逐渐稳住。

## 物理模型

| 阶段 | 模型 |
|------|------|
| 器材派生 | AMO 静挠度反推抗弯刚度 EI；由 GPI/箭头/羽毛算质量、质心、FOC、转动惯量 |
| 弓上阶段 | 每横向通道 3 自由度：质心侧移 + 刚性偏航 + 一阶弯曲模态；含手指滑出力、侧垫/弓把弹性接触、弦横向恢复力 |
| 自由飞行 | 刚体质心 6DOF（四元数姿态）+ 两向弯曲模态；重力、轴向阻力、法向风标力、转动气动阻尼、侧风/逆风 |
| 标定项 | `DRAG_GAIN`（阻力）、`WEATHERVANE_GAIN`（质心法向力/风偏）、`RESTORE_GAIN`（转动恢复） |

右手弓口径：**偏硬的箭左偏、偏软的箭右偏**；羽毛越大摆正越早；轻箭头初速大、落点更高。

## 验收指标（`npm test`，15 项全过）

- 同弓下硬箭→左、软箭→右，落点随挠度单调，与教练选箭表方向一致
- 羽毛面积越大，箭身偏航衰减到 10% 的时间越短（大 45ms / 中 71ms / 小 162ms）
- 轻箭头落点高于标准箭头（+63cm），重箭头下沉
- 70m 侧风 0–8 m/s，着靶偏移与手册瞄点修正表最大误差 **0.03 环**（要求 ≤1 环，环宽 6.1cm）
- 插靶偏航/俯仰角有限且物理合理；6 张弓全部可完成完整射箭

## 四个页面

1. **弓箭搭配** — 选弓选箭选拉距，动态挠度匹配判定、选箭表曲线图、手册风偏表、器材派生参数
2. **射箭场** — WebGL2 三维场景，调风/误差/瞄具，撒放后播放飞行轨迹与弯曲，显示环数与插靶角
3. **慢放分析** — 弓上弯曲阶段 + 自由飞行逐帧回放，q(t) 弯曲模态与 yaw(t) 偏航曲线、离弦状态
4. **成绩** — 环靶落点图、统计、历史记录（localStorage 持久化）

## 器材目录

`src/physics/catalog.ts` 内置 3 张传统弓（英式长弓、满洲角弓、蒙古骑弓）+ 3 张竞技反曲弓（32/40/48#），
10 支不同挠度/长度/箭头重量/羽毛尺寸的碳箭与木箭。

## 开发

```bash
npm install
npm run dev      # 开发服务器
npm test         # node:test 物理 + 渲染 + DOM 测试
npm run build    # tsc 类型检查 + vite 生产构建
```

代码结构：

```
src/physics/   纯 TypeScript 物理（无 DOM 依赖，可独立测试）
  beam.ts        自由梁模态形函数/模态质量刚度/固有频率
  derive.ts      AMO 挠度→EI、质量惯量 FOC、动态匹配指数、储能与初速
  launch.ts      弓上阶段（弓箭手悖论）
  flight.ts      自由飞行 6DOF + 弯曲模态 + 气动
  shot.ts        完整射箭编排、双轴归零、手册风偏表、匹配判定
src/webgl/     WebGL2 渲染器、mat4、弯曲箭杆网格
src/ui/        四个页面与控件
```
